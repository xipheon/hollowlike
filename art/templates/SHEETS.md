# Sprite sheet layouts

Generated by `tools/make_art_templates.gd`. Don't edit by hand: change `SHEETS` in the script and rerun it.

Every sheet is a grid of equal frames. Each row is one animation, read left to right, starting at the left edge. Grey cells with an X are unused, so leave them empty.

Guide colours:

- **Blue box**: the collision box. The body should roughly fill it.
- **Red cross**: the pivot, the point the game lines the sprite up on.
- **Dotted line**: the centre line.

## tileset

- Guide: `art/templates/tileset_guide.png`
- Save the art as: `art/tiles/tileset.png`
- Tile: 32 x 32 px; the sheet is 8 x 7 tiles (256 x 224 px)

**Solid terrain (the top-left 4x4 block)** uses Godot's *Match Sides* terrain. Each tile is painted from the ASCII `#` map according to which of its four neighbours are solid. An orange strip marks an exposed edge: a side that faces open air, where the grass, rim or crust goes. Each terrain tile should tile seamlessly with its neighbours.

**Other tiles.** The blue dotted line marks a size the game uses:

| Tile | What it is |
|---|---|
| PLAT L / MID / R / ONE | One-way platform (`=`). Its collision is the top 10 px. ONE is a single-tile platform. |
| SPIKE, SPIKE 2-4 | Floor spikes (`^`). The damage area is the bottom 24 px. Four variants so a long row doesn't repeat. |
| GATE / GATE END | Arena gate (`|`), shut: the middle of the column and its bottom tile (spiked tips). |
| GATE UP | Raised gate: only the tips peek out, about 8 px. |
| ACID TOP 1-4 | Acid surface (`~` with air above). The liquid starts 8 px down. 4 animation frames. |
| ACID FILL 1-4 | Acid below the surface. 4 animation frames. |
| DOOR / DOOR TOP | Door (`>`). DOOR TOP sits under solid rock, with a 6 px frame. |
| DECOR | Free cells for background or decoration tiles (moss, chains, cracks), placed by hand later. |
